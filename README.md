# 🚀 Desafio de Projeto: Git, GitHub e Markdown

Este repositório foi desenvolvido como parte de um desafio prático para treinar conceitos de controle de versão com Git, colaboração no GitHub e formatação com Markdown.

---

## 🎯 Objetivos do Desafio

* Praticar comandos e fluxos do Git e GitHub.
* Criar e formatar documentação utilizando Markdown.
* Experimentar fluxos de trabalho colaborativos (Forks, Branches, Issues e Pull Requests).
* Configurar boas práticas de segurança e perfil.

---

## 📋 Checklist de Progresso

- [x] Criar conta no GitHub
- [x] Criar repositório público com README.md
- [x] Editar documentação com sintaxe Markdown
- [x] Treinar fluxo de colaboração (Fork / Clone / Issues / Pull Requests)
- [x] Concluir desafios extras (SSH e README do Perfil)
- [x] Submeter o link do repositório para avaliação

---

## 🛠️ Tecnologias e Ferramentas

| Ferramenta | Uso no Projeto |
| :--- | :--- |
| **Git** | Controle de versão local |
| **GitHub** | Hospedagem de código e colaboração |
| **Markdown** | Formatação e documentação |
| **GitHub.dev** | Editor web no navegador (atalho `.`) |

---

## 💡 Recursos e Aprendizados

> "A prática constante com branches, commits e resolução de conflitos é o que consolida o aprendizado em desenvolvimento colaborativo."

* Repositório editado diretamente no navegador com a tecla `.` (github.dev).
* Uso de sintaxe Markdown para tabelas, citações, listas de tarefas e formatações de texto.
